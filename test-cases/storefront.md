# Мануальные кейсы: витрина

Выберите **один** кейс из списка ниже. Источник: чек-лист Medusa QA (лист «Тест-кейсы», связанные проверки из листа «Регрессия»).

Цены и количества в кейсах взяты с эталонного стенда. На вашем стенде могут быть внедрённые ошибки, поэтому ожидаемый результат кейса — это требование, а не гарантия того, что приложение так себя ведёт.

| ID | Сценарий | Приоритет | Страницы | Page Object |
|----|----------|-----------|----------|-------------|
| [TC-03](#tc-03-выбор-варианта) | Выбор варианта | P0 | карточка товара | есть: `ProductPage` |
| [TC-05](#tc-05-количество-и-сумма) | Количество и сумма | P0 | карточка товара, корзина | нет: корзина |
| [TC-07](#tc-07-валидация-обязательного-адреса) | Валидация обязательного адреса | P0 | checkout | нет: checkout |
| [TC-11](#tc-11-невалидный-email) | Невалидный email | P1 | checkout | нет: checkout |
| [TC-12](#tc-12-сортировка-товаров) | Сортировка товаров | P1 | каталог | есть: `StorePage` |

Общее для всех кейсов:

- **Роль:** гость (тест использует `SESSION_STORAGE_STATE`, как `tests/store/catalog.spec.ts`).
- **Товар:** Medusa T-Shirt (`/dk/products/t-shirt`), опции Color (Black, White) и Size (S, M, L, XL), 8 вариантов.
- **Регион:** Denmark (`/dk`), валюта EUR.
