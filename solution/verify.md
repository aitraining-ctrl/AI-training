## Проверка на false positive

Как убедились, что негативный тест падает на невалидных данных (что изменили, какой получили результат):

## Чек-лист

- [ ] Оба теста запущены против стенда, а не просмотрены визуально
- [ ] На валидных данных тест проходит, на невалидных падает (нет false positive)
- [ ] Нет жёстких пауз (`waitForTimeout` и аналогов), только ожидания по условию
- [ ] Локаторы проверены на устойчивость (`data-testid` или роль, без индексов и XPath)
- [ ] 2 прогона подряд без флака
- [ ] `npm run lint` и `npm run typecheck` проходят
